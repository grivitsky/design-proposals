# design-proposals

Static proposal pages. One folder per proposal. `vercel.json` sets `cleanUrls`, so each folder is served without `/index.html`.

## Proposals

- [Proximal Ventures](/proximal-vc) — design proposal, Mikita

## Type

The page is set in Inter, the free stand-in for SF Pro. One variable file is self-hosted under `proximal-vc/assets/fonts/` (SIL Open Font License).
