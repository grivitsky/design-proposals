# design-proposals

Static proposal pages. One folder per proposal, with its own HTML, CSS, and assets. `vercel.json` sets `cleanUrls`, so a folder is served at a path without `/index.html`.

## Proposals

- [Proximal Ventures — Brand & Web Proposal](/proximal-vc) — Mikita, November 2026

## Type

Saans, Saans Mono, and Serrif are the reference faces and are not freely available. Substitutes are self-hosted from Google Fonts under the SIL Open Font License:

| Reference | Substitute |
| --- | --- |
| Saans | Inter |
| Saans Mono | IBM Plex Mono |
| Serrif | Newsreader |
